# DocOnGo-Frontend
DocOnGo AI is an AI-powered healthcare platform that provides users with instant medical guidance through a simple and intuitive interface. The goal of the project is to make basic health assistance more accessible by allowing users to describe their symptoms and receive AI-generated suggestions anytime, without waiting for appointments.

The platform offers secure user authentication, AI-driven symptom analysis, personalized health recommendations, and a clean, responsive interface that works seamlessly across devices. It is designed with privacy in mind, ensuring that user health information is handled securely while delivering fast and reliable responses.

Developing this project helped me strengthen my skills in building full-stack AI applications, integrating large language models (LLMs), designing secure REST APIs, implementing authentication, managing databases, and creating modern, user-friendly interfaces. It demonstrates my ability to combine AI with web technologies to build practical applications that improve everyday user experiences.
